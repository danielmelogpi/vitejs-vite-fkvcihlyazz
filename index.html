vue-pdf-embed lab

Ways to render a PDF in a Vue app, compared. Findings live in ai-planning/vue-pdf-embed/findings.md. Weights are real per-entry totals from npm run measure; “adds” is what each option contributes on top of the 26 KB gzip Vue baseline every page shares. This page itself ships no JS.

  • vue-pdf-embed
    pdf.js under the hood. Full JS API: page count, text layer, annotations, smooth scroll-to-page. 823 KB gzip — adds ~797 KB.
  • native <embed>
    The browser's own viewer, via <embed> / <object> / <iframe>. Free toolbar, but no JS API and no scroll-to-page without a reload. 29 KB gzip — adds nothing (no library).
  • pdfobject-vue
    The native tag plus capability detection and a download-link fallback, same ceiling as the native tag. 30 KB gzip — adds ~4 KB.
