PDF rendering lab

Ways to render a PDF in a Vue app

Comparison matrix — every aspect scored side by side, with the evidence behind each call.

  • vue-pdf-embed
    pdf.js under the hood. Full JS API: page count, text layer, annotations, smooth scroll-to-page. 828 KB over the wire.
  • pure canvas (pdf.js core)
    Same pdf.js, no wrapper: our own canvases, lazy per-page rendering, no Safari polyfill needed. 155 KB over the wire, plus a 470 KB worker on first document.
  • annotpdf → native
    Writes real annotations into the PDF bytes in the browser, then lets the native viewer draw them. The only option that can create annotations. 84 KB.
  • native <embed>
    The browser's own viewer, via <embed> / <object> / <iframe>. Free toolbar, but no JS API and no scroll-to-page without a reload. 31 KB over the wire — no library at all.
  • pdfobject-vue
    The native tag plus capability detection and a download-link fallback, same ceiling as the native tag. 33 KB over the wire.
