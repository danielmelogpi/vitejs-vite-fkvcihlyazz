PDF rendering lab

Ways to render a PDF in a Vue app

Comparison matrix — every aspect scored side by side, with the evidence behind each call.

  • vue-pdf-embed
    pdf.js under the hood. Full JS API: page count, text layer, annotations, smooth scroll-to-page. 828 KB over the wire.
  • pure canvas (pdf.js core)
    Same pdf.js, no wrapper: our own canvases, lazy per-page rendering, no Safari polyfill needed. 155 KB over the wire, plus a 470 KB worker on first document.
  • annotpdf → native
    Writes real annotations into the PDF bytes in the browser, then lets the native viewer draw them. The only option that can create annotations. 84 KB.
  • @cantoo/pdf-lib → native
    Maintained pdf-lib fork with encryption, PDF/A and incremental save. Writes annotations or drawn content; cannot render or zoom. ~257 KB of library.
  • @pdfme/pdf-lib → native
    The same core without the extras, and the lighter of the two maintained forks. ~224 KB of library.
  • unpolyfilled → iframe fallback
    The same pdf.js viewer with the Safari polyfill left out, so it breaks where Safari breaks. Detects the failure and degrades to the browser's own viewer — which still costs the full 830 KB, because pdf.js has to download before it can fail.
  • Document AI matches → annotations
    Upload a Document AI response and its PDF. Lists every match, flags the ones with no bounding box, and writes the selected ones into the PDF as annotations.
  • native viewer coordinate jumps
    Document AI boxes converted to PDF points and pushed through the URL fragment (#page=N&zoom=scale,left,top). No pdf.js — it scrolls, it does not highlight.
  • print-on-open guard
    Some documents carry /OpenAction → this.print() and Firefox obeys it. Tries every way of catching or blocking that from the embedding page.
  • native <embed>
    The browser's own viewer, via <embed> / <object> / <iframe>. Free toolbar, but no JS API and no scroll-to-page without a reload. 31 KB over the wire — no library at all.
  • pdfobject-vue
    The native tag plus capability detection and a download-link fallback, same ceiling as the native tag. 33 KB over the wire.
